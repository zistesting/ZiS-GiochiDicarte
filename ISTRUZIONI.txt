>>> ATTENZIONE, LEGGI PRIMA DI CARICARE <<<

Le immagini adesso sono in WebP, non piu' in PNG (e velvet non e' piu' un JPG).
I nomi delle risorse non cambiano, cambia solo l'estensione del file.

Se nel repository c'e' gia' la vecchia cartella  app/src/main/res/drawable-nodpi
con i PNG, quei file VANNO CANCELLATI PRIMA. Se restano, il repository si ritrova
card_0_1.png e card_0_1.webp insieme e la build si ferma con
"duplicate resource" / "Duplicate resources".

Il modo piu' rapido su GitHub: apri  app/src/main/res/  , entra in drawable-nodpi,
poi dal menu "..." in alto a destra della cartella scegli Delete directory e conferma
con un commit. Dopo, carica gli 87 file nuovi.

--- caricamento ---

Carica il CONTENUTO di questa cartella nella radice del repository, non la cartella
"parte2" stessa: la app/ che trovi qui si fonde con quella della parte 1 e le immagini
finiscono in  app/src/main/res/drawable-nodpi/

In alternativa, se quella cartella esiste gia' nel repository (ed e' vuota), entraci e
carica direttamente gli 87 file con Add file -> Upload files.

Le immagini NON vanno spostate in drawable/: devono restare in drawable-nodpi,
altrimenti Android le ingrandisce alla densita' dello schermo e l'app spreca memoria.
